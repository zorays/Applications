# Bijli Haazir — Testable Postulates

**Public working checklist · 18 November 2026.** A check means the evidence gate has been achieved and linked in a PR/issue—not merely that the team believes the claim. Suggested owners are placeholders pending explicit team agreement.

## Customer

- [ ] **P01 — Motorway drivers will pay for on-demand rescue energy.**  
  **Test:** Interview 30 EV drivers; measure willingness-to-pay and call-out urgency.  
  **Evidence gate:** >=10 qualified pilot requests or LOIs  
  **Proposed owner:** Customer  
  **Link to evidence:** _pending_

- [ ] **P02 — A host location has unmet DC charging demand.**

  **Evidence gate:** One signed LOI / written trial permission  
  **Proposed owner:** Business  
  **Link to evidence:** _pending_

- [ ] **P03 — Rider fleets swap enough times each week to create recurring revenue.**

## How to work one by one

1. Assign one person responsible for each postulate. 2. Define budget, test date and evidence format. 3. Gather source, lab result, quote, LOI or transaction record. 4. Review with another team member. 5. Check only when the evidence gate is satisfied. 6. Link the supporting evidence and note the decision. 7. Update the GitHub issue / markdown source as the team's shared record.
